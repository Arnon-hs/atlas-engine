# Code of Conduct

This project welcomes participation across backgrounds, identities, and levels
of experience. Discuss technical decisions with evidence and treat people with
respect. Ask questions in good faith; accept correction; give actionable feedback;
respect privacy and boundaries.

Harassment, threats, discriminatory or sexualized abuse, doxxing, deliberate
intimidation, and repeated disruption are not acceptable. Do not publish personal
or private information without permission. These expectations apply to project
issues, pull requests, discussions, and any event or channel acting for the project.

Maintainers may edit or remove harmful content, pause a discussion, warn a
participant, limit participation, or ban accounts, proportionate to the harm and
pattern. Explain decisions where doing so is safe. Conflicts of interest should
be disclosed and another maintainer should handle a report when available.

For conduct affecting GitHub interactions, use the relevant
[GitHub abuse-reporting channel](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Do not publish sensitive details in a project issue. A dedicated confidential
project conduct contact and an independent appeals contact have not yet been
appointed; the owner must do so before broader community launch. The project does
not claim a staffed moderation team or a private reporting inbox it does not have.

An appeal should go to a maintainer not involved in the original decision when
one has been appointed. Until then, GitHub's platform process remains available
for platform abuse. Vulnerabilities in software follow [SECURITY.md](SECURITY.md).

This is an original, project-specific policy informed by
[Your Code of Conduct](https://opensource.guide/code-of-conduct/), not a copied
or renamed Contributor Covenant.
