# Maintainers and access

| Identity | Known role | Not yet verified |
| --- | --- | --- |
| [Arnon-hs](https://github.com/Arnon-hs) | Owner of `Arnon-hs/atlas-engine` on GitHub | Full collaborator/access inventory, release and security delegates |

This is not a complete access attestation. Before launch, the owner must inspect
repository/organization roles, list everyone with sensitive access, appoint a
backup responder and reviewer, and record a review date. Never list invented
maintainers or claim two-person review from a single owner.

Maintainers are responsible for issue triage, non-author code review, dependency
and security findings, schema compatibility, accurate documentation, and release
verification. Support is best effort. Privilege escalation requires documented
review under [GOVERNANCE.md](GOVERNANCE.md), not automatic promotion. Release and
security access should be limited separately where the platform permits.
